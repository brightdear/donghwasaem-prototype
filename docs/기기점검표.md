## ko-KR 음성이 없을 때

설정 > 텍스트 음성 변환(음성 출력) > 한국어 데이터 설치 후 브라우저를 완전히 닫았다 다시 연다. iPad 는 설정 > 손쉬운 사용 > 말하기 콘텐츠 > 음성 > 한국어에서 음성을 내려받는다. 그래도 없으면 실험자 낭독 모드로 진행하고 `manualReading=true` 세션은 분석에서 제외하거나 따로 본다.
