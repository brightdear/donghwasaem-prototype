## 1. 참가자 코드 배정표

코드 R01~R14 (R 접두는 분석 제외). 이야기 2 x 조합 7. 기기마다 두 이야기가 모두 들어가도록 배정했다.
조합 7개: 분기 off / rewind + 이유 on / rewind + 이유 off / converge + 이유 on / converge + 이유 off / altEnding + 이유 on / altEnding + 이유 off.

|---|---|---|---|---|

## 2. 매 세션 절차

1. 실험자 화면에서 참가자 코드·이야기·조건 입력 → '아이에게 넘기기'.
2. 대본대로 진행. 끝나면 부모 넘김 화면 → 리포트 확인.
3. **'물어봤어요' 체크**(체크 대기 상태 해소).
4. **JSON 내보내기**.
5. 아래 기록표 작성. 중간에 새로고침·재시작이 있었으면 비고에 적는다.
6. 방문(하루 일정)을 마치면 **API 키 삭제**.

## 5. 통과 기준과 회복 경로

- **통과**: 14경로 완주 + 오류 0건 + 키를 넣은 세션 중 `report_source=llm` 1건 이상.
- **회복**: 시나리오 텍스트만 고쳤으면 실패 경로와 같은 이야기의 남은 경로만 다시, 엔진·로그·TTS 코드를 고쳤으면 14경로 전체를 다시 한다. 고친 뒤에는 Actions 초록과 배포 커밋 해시, 대본 생성 시각을 다시 기록한다.
