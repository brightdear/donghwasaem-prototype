## 4. 구조 메모 (리드·엔진 확인용)

- 개미와 베짱이 spine은 p1 → c1 → p2 → c2 → p3 → c3 → p4 → end. 흥부와 놀부 spine은 `p1 → c1 → p2 → c2 → p2n → p3 → c3 → p4 → end`(2026-10-25 놀부 제비·박 장면 p2n 추가). 마지막 선택(c3) 뒤에 짧은 척추 p4(봄 장면)를 두어 결말 앞에서 경로가 다시 합쳐지게 했다.
- c1·c2는 보기 2개, c3은 보기 3개(원작 1 + 다른 선택 2).
- endings.alt는 어느 선택 지점에서 다른 선택을 했든 어울리도록, 특정 사건을 단정하지 않는 "다음에는 내가 먼저 손을 내밀어야지" 결말로 썼다(2026-10-25부터 UI에서 선택 불가, 데이터만 유지).
